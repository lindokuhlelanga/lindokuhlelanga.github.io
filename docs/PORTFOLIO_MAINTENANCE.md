# Portfolio Maintenance Checklist

Use this checklist before sharing the portfolio with recruiters.

## Personal information

- [ ] Name is current and consistent
- [ ] Email is current
- [ ] LinkedIn works
- [ ] GitHub works
- [ ] Location wording is current
- [ ] No student numbers are public
- [ ] No private credentials are public

## Education and employment

- [ ] BEngTech Computer Engineering status is accurate
- [ ] Honours status is accurate
- [ ] Academic average is accurate
- [ ] Current employment dates are accurate
- [ ] No outdated graduation wording remains

## Skills

- [ ] Only list technologies you can discuss confidently
- [ ] Do not use arbitrary skill percentages
- [ ] Do not list AWS unless intentionally re-added later
- [ ] Separate programming, software/data, security, networking and embedded skills

## Projects

For each featured project:

- [ ] Repository link points to the exact project
- [ ] README is complete
- [ ] Source code is present where it can be shared
- [ ] Screenshots are readable
- [ ] Results are supported by project evidence
- [ ] No exaggerated or invented metrics
- [ ] No assessment-only or private material
- [ ] No secrets/tokens/passwords

## Resume

The website currently expects a file named:

`Lindokuhle_Langa_CV.pdf`

When the general portfolio resume is updated, replace that file with the latest recruiter-safe general CV. Keep job-specific CVs separate rather than constantly replacing the portfolio resume.
